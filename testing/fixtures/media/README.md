# Media fixtures

Served by [`../server.py`](../server.py) for the media player's device checks (`MediaPlayerTest`). Synthetic content only.

## `clip.mp4`

- 4,712 bytes: H.264 Constrained Baseline, level 3.0, 320×180, 30 fps, 6.000 s, no audio, `moov` before `mdat`.
- Two solid halves: `#2e6b4f` for the first 3 s, then `#3b4f8a`. The device check samples both colours (`Device.GREEN` and `Device.BLUE`).
- SHA-256 `ec7875cf658a2ea68bd825088fe8a09d30cc7090fbc5d0561f726aead61488f5`. `server.py` checks it at start-up and exits if the file differs.

Made with ffmpeg 6.1.1-3ubuntu5 (Ubuntu 24.04), which gave the same bytes on two runs:

```sh
ffmpeg -f lavfi -i "color=c=0x2e6b4f:s=320x180:r=30:d=3,format=yuv420p[a];color=c=0x3b4f8a:s=320x180:r=30:d=3,format=yuv420p[b];[a][b]concat=n=2:v=1:a=0" -c:v libx264 -profile:v baseline -level:v 3.0 -pix_fmt yuv420p -g 30 -bf 0 -bsf:v filter_units=remove_types=6 -fflags +bitexact -flags:v +bitexact -map_metadata -1 -movflags +faststart clip.mp4
```

The bytes are committed rather than regenerated: other x264 or ffmpeg versions can encode them differently. `filter_units=remove_types=6` drops x264's SEI message, which names the encoder version and its options.

## `seg-a0.aac`, `seg-a1.aac`

- 13,640 and 13,654 bytes: AAC-LC in ADTS frames, 64 kbps, 44.1 kHz, mono, about 3 s each; 440 Hz and 550 Hz tones.
- The audio playlist of the HLS fixture (`/media/hls-audio.m3u8`): sites that stream HLS, X included, carry audio on a separate playlist.

Made with afconvert (macOS) from generated sine WAVs:

```sh
afconvert -f adts -d aac -b 64000 seg-a0.wav seg-a0.aac
afconvert -f adts -d aac -b 64000 seg-a1.wav seg-a1.aac
```

The bytes are committed rather than regenerated: another encoder can encode them differently.

## Generated by the server

`/media/tone.wav` is not a file: `server.py` builds it with `struct` (a 440 Hz tone, 16-bit PCM, 8 kHz, mono).

The HLS video segments are not files either: `server.py` remuxes `clip.mp4`'s samples into an fMP4 init segment (`/media/hls-init.mp4`) and two 90-sample media segments (`/media/hls-video-{0,1}.m4s`, green then blue, split at the keyframe on the boundary) with only the boxes rebuilt.
