# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Page controls: `<select>` pickers, `alert`/`confirm`/`prompt` dialogs
  naming the asking site (with a way to block a page's repeated dialogs),
  and file upload through Android's document picker.
- Third-party notices in Settings › About: the engine's Rust crates and
  bundled C/C++ libraries, generated by `scripts/generate-notices.py`, and
  the Java/Kotlin libraries, checked and listed by the Licensee plugin.
- Long-press on a link or image: open in a new tab, copy or share the
  address.
- HTTP sign-in: a dialog naming the server asks for a username and
  password, warns on unencrypted connections and stores nothing.
- Device check that the bottom bar, More menu and page dialogs keep 48dp,
  labeled touch targets at the narrowest width and largest font size.
- Local release signing through environment variables, with explicit validation
  of incomplete configuration and no committed signing material.
- APK build-script regressions in CI and SHA-256 sidecars for local builds.
- App icon master (`media-sources/icon.png`).
- Implementation plan, integration evidence, design reference, and
  documentation checks.
- Repository tooling ahead of the app: build, install, and release scripts;
  CI and tag-triggered release workflows; GLM code review; Dependabot.
- M0 engine spike: Servo v0.6.0 pinned with three patches, Combray's Rust
  bridge (`native/`), an Android test harness and fixture site (`spike/`),
  build and check scripts (`scripts/m0/`), and the results in
  `docs/ENGINE_SPIKE.md` and `docs/BUILDING.md`.
- The Combray app (`app`, `core`, `engine` Gradle modules): Servo tabs with
  durable logical state, bottom bar, address and Kagi search, unified Recent
  with local filter, retention and forgetting, external links, page-opened
  windows, and recovery after process death.
- Karakeep saves: protected credentials bound to their server, a durable
  outbox with fenced claims, retries and honest pending/saved/failed states.
- Hister: opt-in capture of rendered page text with exclusions, budgets and
  per-document ordering, plus explicit long-term search in Recent.
- Servo patch 0004: cookies and other profile state are written on request
  (and atomically), so logins survive Android killing the app.
- Device checks against the real engine (`scripts/check-app.sh`) with
  synthetic pages and fake services (`testing/fixtures/`).
- Internationalized host names show in Unicode only when they cannot
  imitate another site; other hosts show as punycode.
- Karakeep and Hister take plain `http://` addresses, with a warning in
  Settings about what travels unencrypted.
- A second address for each service, such as a Tailscale address for use
  away from home. Combray tries the address that last answered and
  switches only when the other cannot be reached, so a request is never
  sent twice.
- Settings › Local history: an option to close tabs unused for seven days.
- Reader view (More › Reader view): the page's article as plain text with
  links, found by Mozilla's Readability.js (Apache-2.0, vendored) inside
  the page and listed in the third-party notices.
- A Karakeep scope in Recent: the newest bookmarks, or Karakeep's search
  for what you type; a result opens in a new tab.
- Settings › Karakeep › List for saves: saved pages are also added to a
  manual Karakeep list you choose.

### Changed

- Settings' history-retention label now reads the same configured
  retention instance maintenance runs with, instead of building its own
  copy of the default.
- Share is in the bottom bar, next to Save, instead of the More menu.
- Recent opens on Open tabs. All, Hister and Karakeep are chips beside it;
  Hister search moved there from the "Search all history" button.
- A closed tab's page keeps its place in Recent, ordered by when the tab
  was last used rather than moved to the top.
- Back on a page another app's link opened returns to that app; the page
  stays in history only, unless you switched tabs meanwhile.
- `scripts/build.sh` builds the engine first: it installs the pinned NDK
  and Rust toolchain when missing and fetches, verifies and patches Servo
  whenever the tree is missing or was prepared with other patches. Builds
  default to arm64; set `COMBRAY_ABI=x86_64` for the emulator. The build
  and check scripts also select the NDK's macOS tools and fall back to
  `shasum` (not yet verified on macOS).
- Gradle 9.8.1, Kotlin 2.4.21 and Room 2.8.5.
- CI also compiles the device checks, fails when Room's exported schemas
  are not committed or a committed version's schema changed, and checks
  the engine bridge's Rust formatting and page-script syntax.

### Fixed

- A huge `Retry-After` header no longer overflows into an immediate
  retry: the seconds are clamped to the six-hour ceiling before
  conversion to milliseconds.
- Tapping Save with Karakeep not set up now says so even when the address
  looks like it carries a login token, instead of claiming the address was
  withheld for safety.
- Credential-bearing parameter names are matched after a single percent-decode,
  so an encoded `token`/`access_token`/`auth` name in a query or fragment is
  still sensitive and is never sent to Karakeep or captured for Hister.
  Double-encoded names and ordinary parameters are unchanged, and escapes the
  decoder rejects remain conservative (sensitive).
- The Recent tab-count badge caps its visible label at "99+" so large
  counts fit the badge; TalkBack still hears the exact number.
- An engine that fails before it is ready (for example a graphics driver
  error) now shows the engine-failed message instead of claiming the
  engine is still starting forever.
- Hister search no longer shows a "More results" button that does nothing
  after the last page, or under "No results in Hister." While more results
  load, the button waits under a progress bar; if they fail, the reason
  shows above the results.
- Changing Karakeep's server address cancelled every unsent save without
  a word. Those saves now wait in Settings, which offers to send them to
  the current address or discard them.
- In Recent, the current tab stays above the pages you browsed in it and
  under the right day. A page you navigate away from is kept for seven days
  from when you left it, not from when it loaded.
- Sites built on Next.js, such as anthropic.com, replaced their page with
  "This page couldn't load": Servo 0.6.0 leaves IntersectionObserver off by
  default, and their start-up code needs it. Combray now enables it.
- docs.mistral.ai showed "Application error: a client-side exception has
  occurred": Servo 0.6.0 has no `Element.animate()`, which its marquee
  calls. Pages now get the web-animations-js polyfill (Apache-2.0,
  vendored), installed on the first use of `animate()`, `getAnimations()`
  or `document.getAnimations()` so other pages are unaffected. If the
  polyfill cannot install, every later call reports that cause instead of
  "not a function".
- Reader view drops an article whose renderer has crashed or been
  replaced. The late callback no longer covers the page now on screen.
- `scripts/m0/fetch-servo.sh` applied none of Combray's Servo patches in a
  clone of this repository: `git apply` skipped their files and still
  succeeded, so the engine failed to compile (`no PipelineId in the root`).
  Each patch is now checked to have landed.
- Abandoned Hister captures expire after seven days, including when a
  running queue crosses the age limit. Expiry clears page bodies and
  rejects late results without invalidating a live request's lease.
- A page's prompt dialog labels its text field, so TalkBack names it.
- A device check whose fixture server could not start (another run holds
  the port) now stops and says so instead of testing against no page and
  reporting timeouts.
- `scripts/check-app.sh` skipped the reader view checks: its default run
  now covers every device-check class, and `--list` prints them.
- Forgetting a page or site commits local deletion and queued Hister
  cancellation together, so a crash cannot leave forgotten text queued.
- Device-check summaries no longer pass a run whose app process crashed or
  was killed as not responding after some checks passed: the check in
  progress shows as crashed and the unreached ones as not run.
- Reader view leaves a page whose address changes, including single-page
  and hash-routed navigation, and drops its delayed article result.
- Local APK names now use the packaged architecture instead of always saying
  arm64. Staging rejects missing native libraries, wrong ELF architectures and
  stale APKs that do not match Gradle output metadata. Failed copying or
  hashing preserves the previous APK and checksum. Release CI applies the same
  packaging checks before staging an arm64 artifact.
- A Karakeep save with a chosen list stays pending if its acknowledgment
  has no usable bookmark ID. Duplicate-safe retries recover the ID and
  finish list membership, or stop with a visible failure.
- A `data:` page could make the address chip, Recent and its dialog titles
  name another site by putting `://` and that site's name in its own
  address. Pages without a host now show only their scheme ("data:",
  "about:blank", "file:"), and their dialogs say "This page says".
